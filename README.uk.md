# rotary-pico

## 1. Опис

Керуючий модуль для саморобного поворотного стола (turntable) під 3D-сканер типу Creality Raptor, на базі плати **BTT SKR Pico** (RP2040, MicroPython).

- **Вісь X** — обертає стіл (безкінечне обертання, керування швидкістю).
- **Осі Y/Z** — циклічний рух між нижньою та верхньою межею, без фізичних кінцевиків: StallGuard (sensorless homing) TMC2209 виявляє, коли механізм упирається в реальну межу, і автоматично коригує `MIN`/`MAX` під цю позицію.
- **Сервопривід ST3215** — нахиляє голову сканера (циклічний рух між мінімальним і максимальним кутом).

Усі осі працюють одночасно та незалежно одна від одної (кооперативна багатозадачність на `uasyncio`), керування — консольними командами у стилі G-code.

Проєкт надихнений відео [Creality Raptor Turntable](https://www.youtube.com/watch?v=kjL7HI78B2U&t=881s) — у `table_models/` додані моделі поворотного стола цього ж автора.

### Файли проєкту

| Файл / папка | Призначення |
|---|---|
| `tmc2209.py` | Драйвер TMC2209 через UART (спільна шина, адресація по MS1/MS2) |
| `st3215.py` | Драйвер сервоприводу ST3215 (протокол Feetech SMS/STS) |
| `scanner_rig.py` | Оркестратор: асинхронні задачі X/Y/сервo + консольний парсер команд |
| `main.py` | Простий стендовий тест одного мотора (bring-up/діагностика) |
| `freecad/` | Власні моделі FreeCAD (кроковий двигун, кріплення сервоприводу) |
| `table_models/` | Моделі поворотного стола (STEP) автора надихаючого відео |

## 2. Система команд

Команди подаються по одній на рядок у консолі (REPL):

| Команда | Опис |
|---|---|
| `START [minutes]` | Запустити всі осі одночасно (з уже налаштованими параметрами кожної), автозупинка через `minutes` (за замовчуванням 5) |
| `STOP` | Негайно зупинити всі осі |
| `X SPEED <steps_per_sec>` | Швидкість обертання столу (знак визначає напрямок, 0 = стоп) |
| `X START [CW\|CCW]` | Почати обертання столу — напрямок опційний, за замовчуванням CW (або останній використаний) |
| `X STOP` | Зупинити обертання столу |
| `Y MIN <steps>` | Нижня межа руху каретки (в мікрокроках) |
| `Y MAX <steps>` | Верхня межа руху каретки (в мікрокроках) |
| `Y SPEED <steps_per_sec>` | Швидкість руху каретки |
| `Y SGTHRS <0-255>` | Поріг StallGuard sensorless-homing (див. нижче) — вище значення = спрацьовує легше |
| `Y START` | Почати циклічний рух каретки між `MIN` і `MAX` |
| `Y STOP` | Зупинити каретку |
| `Z MIN <steps>` | Нижня межа руху осі Z (в мікрокроках) |
| `Z MAX <steps>` | Верхня межа руху осі Z (в мікрокроках) |
| `Z SPEED <steps_per_sec>` | Швидкість осі Z |
| `Z SGTHRS <0-255>` | Поріг StallGuard sensorless-homing (див. нижче) — вище значення = спрацьовує легше |
| `Z START` | Почати циклічний рух між `MIN` і `MAX` |
| `Z STOP` | Зупинити вісь Z |
| `A MIN <deg>` | Мінімальний кут нахилу сканера (градуси) |
| `A MAX <deg>` | Максимальний кут нахилу сканера (градуси) |
| `A SPEED <raw_units>` | Швидкість сервоприводу (внутрішні одиниці регістра, підбирається емпірично) |
| `A START` | Почати циклічний нахил між `MIN` і `MAX` |
| `A STOP` | Зупинити сервопривід |
| `STATUS` | Поточний стан усіх чотирьох осей |
| `HELP` | Довідка по командах |

Приклад сеансу:

```
X SPEED 200
X START
Y MIN 0
Y MAX 3200
Y SPEED 400
Y START
Z MIN 0
Z MAX 3200
Z SPEED 400
Z START
A MIN 30
A MAX 150
A SPEED 300
A START
STATUS
```

### Sensorless homing для Y/Z (StallGuard)

Осі Y та Z не мають фізичних кінцевиків. Замість цього під час руху опитується StallGuard (`SG_RESULT`) TMC2209 через UART — значення падає при зростанні навантаження на мотор, тож упирання в реальну механічну межу читається як "застій" (stall). Коли це трапляється, `MIN`/`MAX` автоматично коригується під реальну позицію зупинки, і вісь реверсується — без "прогризання" механізму в упор.

Універсального значення `SGTHRS` не існує — воно залежить від конкретного мотора, струму, швидкості та механіки, тож підбирається вручну:

1. Виставте низький `SGTHRS` (наприклад 1-3) і запустіть вісь (`START`).
2. Спостерігайте в консолі за повідомленнями `Y StallGuard tripped at pos=... (MIN/MAX)`.
3. Спрацьовує на вільному ході (без реальної перешкоди) → зменшуйте `SGTHRS`.
4. Не спрацьовує при реальному упорі в межу → збільшуйте `SGTHRS`.
